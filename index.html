goBILDA-Compatible Sprocket Generator

Builds a sprocket for goBILDA's 8mm pitch chain system (ISO 606 05B), the same pitch and roller geometry used across goBILDA's 3311 / 3312 / 3313 series parts. Set the tooth count and bore, then export a scaled SVG or DXF profile.

Tooth Count

goBILDA's own 14mm-bore catalog spans 14 to 60 teeth. 14 is the smallest count that clears their 16mm hub-mount pattern.

Bore Type

"A/F" = across flats, the flat-to-flat width of the hex bore.

Offset is applied to the bore diameter (round) or across-flats width (hex). Negative values shrink the hole for an interference/press fit; positive values open it up for a looser slip fit.

Tooth geometry is reverse-engineered directly from goBILDA's own CAD: the published STEP files for parts 3311-0014-0016 (16 tooth) and 3311-0014-0018 (18 tooth) were parsed at the surface/edge level to recover the exact profile — a roller-seat arc, two small transition arcs, a short straight flank, and a true outside-diameter land per half-tooth — rather than approximated from generic chain-sprocket formulas. The outside diameter follows goBILDA's own exact rule, OD = 1.25 × teeth + 2.1 mm, confirmed against both reference parts. Other tooth counts are generated by holding the seat/transition geometry fixed relative to each roller (the representation that stayed consistent between the two reference parts) and scaling the pitch circle accordingly. This tool exports a 2D profile (SVG/DXF) for reference, CNC, laser-cutting, or as a sketch to extrude in your own CAD package — it does not model goBILDA's hub-mount screw pattern or the part's 3D hub boss.
