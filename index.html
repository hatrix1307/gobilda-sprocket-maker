goBILDA-Compatible Sprocket Generator

Builds a sprocket for goBILDA's 8mm pitch chain system (ISO 606 05B), the same pitch and roller geometry used across goBILDA's 3311 / 3312 / 3313 series parts. Set the tooth count and bore, then export a scaled SVG or DXF profile.

Tooth Count

goBILDA's own catalog for this bore covers 14 to 60 teeth. This tool extends the low end further (down to 7) using the same real-geometry construction, verified numerically (watertight, no self-intersection, healthy tooth height). 60 is a genuine ceiling, not just goBILDA's own catalog limit: the outside-diameter formula and the pitch circle grow at very slightly different rates, so tooth height shrinks as tooth count rises and would invert (teeth pointing inward) somewhere past 90 teeth — 60 keeps a comfortable margin.

Bore Type

"A/F" = across flats, the flat-to-flat width of the hex bore.

Offset is applied to the bore diameter (round) or across-flats width (hex). Negative values shrink the hole for an interference/press fit; positive values open it up for a looser slip fit.

SVG/DXF are the flat 2D profile. STL/STEP are a solid extruded to 2.3622 mm — the same plate thickness measured from goBILDA's own 3311-0014-0016/0018 STEP files.

Tooth geometry is a direct reconstruction of goBILDA's own CAD: both published STEP files — 3311-0014-0016 (16 tooth) and 3311-0014-0018 (18 tooth) — were parsed at the surface/edge level (actual boundary curves and their real arc centers, not re-derived approximations) to recover both the exact profile and the real design relationships between its features: a roller-seat arc meets a transition arc at an exact internal tangent point, that arc meets a straight flank tangentially, the flank meets a second transition arc tangentially, and that arc lands exactly on the true outside-diameter circle (a small non-tangent transition there is genuinely present in goBILDA's own geometry, confirmed directly in their STEP data, not an artifact of this tool). The outside diameter follows goBILDA's own exact rule, OD = 1.25 × teeth + 2.1 mm, confirmed exact against both reference parts. The few remaining shape parameters (the transition arc's direction and sweep, and the flank length) are fit against the two reference tooth counts, measured relative to each roller's own radial direction so the fit stays physically meaningful well away from N=16/18 — verified numerically (watertight solids, no self-intersection, healthy tooth height) from 7 to 60 teeth, which is the range this tool exposes. 60 isn't an arbitrary cutoff: goBILDA's own outside-diameter rule (1.25×teeth+2.1mm) grows very slightly slower than the pitch circle does as tooth count rises, so tooth height shrinks with more teeth and would invert entirely somewhere past 90 teeth. 60 keeps a healthy margin below that, and happens to match goBILDA's own real catalog limit for this bore size. This tool exports a 2D profile (SVG/DXF) or an extruded solid (STL/STEP) for reference, CNC, laser-cutting, or 3D printing — it does not model goBILDA's hub-mount screw pattern or the part's 3D hub boss.
